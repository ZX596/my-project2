# 竞赛证书智能识别与管理系统 - 作业提交说明

## 项目概述

本系统是一个基于Streamlit框架开发的竞赛证书智能识别与信息管理平台，通过集成GLM-4V视觉识别API实现证书信息的自动提取，为学校或教育机构提供高效的证书信息采集和管理解决方案。

## 文件说明

### 核心文件

1. **form_handler.py** - 表单处理代码
   - 实现草稿保存功能（保存到drafts.json）
   - 实现批量提交功能（提交到submitted.json）
   - 实现截止时间控制机制
   - 提供数据查询接口

2. **data_export.py** - 数据导出代码
   - 支持导出为CSV格式
   - 支持导出为Excel格式
   - 支持导出为JSON格式
   - 从submitted.json读取数据并导出

3. **admin_panel.py** - 管理员面板代码
   - 查看所有用户提交的数据
   - 查看所有草稿数据
   - 获取统计信息
   - 导出数据功能封装

4. **complete_system.py** - 完整系统主程序
   - 基于Streamlit的用户界面
   - 证书图片上传和Base64编码
   - 信息智能提取（GLM-4V API）
   - 可编辑表单展示提取的证书信息
   - 用户可修改表单中的任意字段
   - 保存草稿和批量提交功能
   - 管理员数据查看和导出功能

### 数据文件

- **form_data/drafts.json** - 存储所有用户的草稿数据
- **form_data/submitted.json** - 存储所有用户提交的数据
- **exports/** - 导出文件目录（CSV、Excel、JSON）

### 配置文件

- **api_config.json** - GLM-4V API配置

## 功能特性

### 1. 证书信息智能提取
- 支持上传JPG、PNG、JPEG、PDF格式的证书
- 自动转换为Base64编码
- 调用GLM-4V API进行信息提取
- 自动填充表单字段

### 2. 可编辑表单
- 展示提取的证书信息
- 用户可修改表单中的任意字段
- 实时验证必填字段
- 支持日期选择器

### 3. 保存草稿功能
- 将数据存储为草稿状态到drafts.json
- 可随时保存和修改
- 不会覆盖已提交的数据

### 4. 批量提交功能
- 提交后数据不可修改
- 提交到submitted.json
- 自动删除对应的草稿
- 验证必填字段和格式

### 5. 截止时间控制
- 截止时间：2025-12-30 18:31:00
- 超过截止时间无法提交
- 实时显示剩余时间

### 6. 管理员功能
- 查看所有用户提交的数据
- 查看所有草稿数据
- 导出数据为CSV格式
- 导出数据为Excel格式
- 统计信息展示

## 使用方法

### 运行系统

```bash
streamlit run complete_system.py
```

### 普通用户操作流程

1. 输入学号（作为用户ID）
2. 选择"普通用户"身份
3. 上传证书图片
4. 点击"抽取信息"按钮（可选）
5. 核实和修改表单信息
6. 点击"保存草稿"或"批量提交"

### 管理员操作流程

1. 输入任意ID
2. 选择"管理员"身份
3. 查看所有提交数据
4. 导出数据为CSV或Excel格式

## 技术栈

- **前端框架**: Streamlit
- **后端语言**: Python 3.x
- **数据存储**: JSON文件
- **API集成**: GLM-4V视觉识别API
- **数据处理**: Pandas
- **文件导出**: openpyxl, csv

## 依赖安装

```bash
pip install streamlit pandas openpyxl pillow requests
```

## 注意事项

1. 首次运行前需要配置api_config.json中的API密钥
2. 确保form_data目录存在
3. 确保exports目录存在（导出时会自动创建）
4. 截止时间可在form_handler.py中修改DEADLINE变量
